## 📌 Featured project

### [Amazon Fine Food Reviews – Sentiment Analysis](https://github.com/soumya-computes/amazon-food-reviews-sentiment)

An end-to-end NLP pipeline that predicts whether a food review is positive or
negative: data cleaning → text preprocessing (negation-aware) → TF-IDF →
model comparison, with tests and CI.

| Model | Accuracy | Macro-F1 | ROC-AUC |
|-------|----------|----------|---------|
| Linear SVM | **94.9%** | **0.907** | **0.982** |
| Logistic Regression | 94.7% | 0.906 | 0.981 |
| Naive Bayes | 92.8% | 0.845 | 0.970 |

<sub>Evaluated on 195k labelled reviews (majority-class baseline: 84.2%).</sub>
